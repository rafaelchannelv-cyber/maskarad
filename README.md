# MaskShow

Сайт бала MaskShow с анкетой участников, базой анкет в Яндекс Облаке и поздравлениями в Telegram.

| Папка / файл | Что это | Где работает |
|---|---|---|
| `index.html` | Сайт с анкетой и чатом | GitHub Pages (публикуется только этот файл, см. `.github/workflows/pages.yml`) |
| `function/` | Облачная функция: принимает анкету, пишет в базу YDB, шлёт пост в Telegram | Yandex Cloud Functions |
| `admin/biblioteka.html` | Библиотека анкет для организаторов (по паролю) | Открывать локально |
| `docs/INSTRUKCIYA.md` | Пошаговая настройка Яндекс Облака и Telegram | — |
| `.github/workflows/deploy-function.yml` | Автодеплой функции при изменениях в `function/` | GitHub Actions |

## Секреты
Ни токенов, ни паролей в репозитории нет и быть не должно. Они хранятся только в переменных функции в Яндекс Облаке и в секретах GitHub (Settings → Secrets and variables → Actions).

## Подключение анкеты
В `index.html` строка `const ANKETA_URL="";`: впишите ссылку облачной функции. Пустая строка = демо-режим, анкета никуда не отправляется.

## Автодеплой
Выключен, пока не заданы секреты. Чтобы включить: добавьте секреты, перечисленные в начале `deploy-function.yml`, и переменную репозитория `DEPLOY_FUNCTION=true`.
