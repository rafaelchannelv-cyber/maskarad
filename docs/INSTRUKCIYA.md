# Библиотека анкет MaskShow: как включить (≈15 минут, один раз)

Анкеты с сайта сохраняются в базу YDB в Яндекс Облаке (серверы в России), а смотреть их можно на странице `biblioteka.html`.
На старте это бесплатно: бесплатного лимита Yandex Cloud Functions и YDB Serverless хватит на тысячи анкет в месяц.

## 1. Аккаунт и база
1. Зайдите на https://console.yandex.cloud и создайте платёжный аккаунт (нужна карта, списаний в пределах бесплатного лимита нет).
2. **Managed Service for YDB → Создать базу данных**, тип **Serverless**, имя `maskshow`.
3. Откройте базу → вкладка **Навигация** → **Новый SQL-запрос**, вставьте и выполните:
   ```sql
   CREATE TABLE anketa (
     id Utf8, created Utf8, name Utf8, continent Utf8, birthday Utf8,
     lastname Utf8, phone Utf8, email Utf8, consent Utf8,
     PRIMARY KEY (id)
   );
   ```
4. На вкладке **Обзор** скопируйте строку **Эндпоинт** (начинается с `grpcs://ydb.serverless.yandexcloud.net:2135/?database=…`).

## 2. Сервисный аккаунт
**Identity and Access Management → Сервисные аккаунты → Создать**: имя `maskshow-fn`, роль `ydb.editor`.

## 3. Облачная функция
1. **Cloud Functions → Создать функцию**, имя `maskshow-anketa`.
2. Среда выполнения **Node.js 18** (или новее), способ — **ZIP-архив**, загрузите `maskshow-function.zip`.
3. Точка входа: `index.handler`. Таймаут: 10 с. Память: 128 МБ.
4. Сервисный аккаунт: `maskshow-fn`.
5. Переменные окружения:
   - `YDB_ENDPOINT` — строка из шага 1.4;
   - `ADMIN_TOKEN` — придумайте пароль библиотеки, **не короче 12 символов**;
   - `ALLOWED_ORIGIN` — адрес сайта, например `https://maskshow.ru` (пока тестируете, можно `*`).
   - `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — для поздравлений в Telegram-канале (см. раздел ниже, можно добавить позже).
6. **Создать версию**. На странице функции включите **Публичная функция** и скопируйте ссылку вида `https://functions.yandexcloud.net/d4e…`.

## 4. Подключить сайт
В файле сайта (`MASKSHOW.html`) найдите строку
```js
const ANKETA_URL="";
```
и вставьте ссылку функции между кавычками. Пока строка пустая, сайт работает как раньше, в демо-режиме.

Важно: сайт должен открываться с вашего хостинга (свой домен или Yandex Object Storage), а не как артефакт claude.ai, потому что артефакт не пускает запросы на внешние серверы.

## 4а. Поздравления в Telegram-канале
1. В Telegram напишите @BotFather → `/newbot`, задайте имя и получите **токен** бота.
2. Добавьте бота в свой канал **администратором** с правом публиковать сообщения.
3. `TELEGRAM_CHAT_ID`: для публичного канала это `@имя_канала`; для закрытого перешлите любой пост канала боту @getmyid_bot и возьмите число вида `-100…`.
4. Впишите оба значения в переменные окружения функции и создайте новую версию.

При каждой регистрации в канал придёт пост «🎉 Поздравляем с новой регистрацией!» с именем, континентом, возрастом и номером участника (№ удобно использовать для розыгрышей в эфире).
Фамилия, телефон и e-mail в Telegram **не отправляются**. Если Telegram недоступен, анкета всё равно сохранится.

## 5. Смотреть анкеты
Откройте `biblioteka.html` в браузере (можно прямо с компьютера, файл не нужно выкладывать в интернет), вставьте ссылку функции и пароль `ADMIN_TOKEN`.
Там есть поиск, фильтр по континентам, счётчики, выгрузка в CSV для Excel и удаление анкеты (например, если участник отозвал согласие).

## Что хранится
Имя, континент, дата рождения, фамилия, мобильный, e-mail, время отправки и текст согласия, которое человек отметил. IP-адреса и прочие технические данные не сохраняются. Боты отсекаются скрытым полем-ловушкой.

## Перед публичным запуском (152-ФЗ)
- уведомить Роскомнадзор об обработке персональных данных (pd.rkn.gov.ru);
- опубликовать на сайте политику обработки персональных данных и дать на неё ссылку рядом с галочкой согласия;
- согласие оформить отдельным текстом (кто оператор, какие данные, цели, срок, как отозвать).
